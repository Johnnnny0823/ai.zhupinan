# 3–4分鐘現場路線與備援

範圍：決賽示範，合成資料；不是正式試辦。展示前先用同一個release重置，先開一次公開離線頁及預存展示頁以完成靜態快取。
展示者持有三個有效一次性登入碼，並確認LINE官方帳號及兩支手機已驗Push與Reply。
若未完成手機實驗，不宣稱LINE已實收，改展示預覽並說明待驗。

## 展示前固定檢查

- 執行`python -m demo.run reset`與`python -m pytest demo/tests -q`。
- 確認`/api/health`示範模式、規則版本、2026／2027日曆。
- 正確來源為PUBLIC_ORIGIN，HTTPS部署時cookie應有Secure。
- A／B互相查不到對方案件；officer不能讀雇主資料。
- 三份合成文件、合成草稿與合成證明入口可用。
- 預存結果與即時模型模式清楚分開；不要只截成功頁。
- 使用無真實資料的展示機；關閉真實文件、LINE私人對話與通知。
